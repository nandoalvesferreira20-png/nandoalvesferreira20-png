## 💻 Projetos em destaque

### 🔹 Loung Prospect — Plataforma de Prospecção Inteligente

**Next.js · TypeScript · Python · FastAPI · SQLite · IA Generativa**

Plataforma desenvolvida para otimizar o processo de prospecção comercial, integrando pesquisa de estabelecimentos, gestão de leads e geração de abordagens personalizadas com inteligência artificial.

**Principais funcionalidades:**
- Busca de estabelecimentos por meio da API Google Places.
- Captura, organização e deduplicação de leads.
- Gerenciamento de oportunidades comerciais e pipeline.
- Geração de mensagens personalizadas utilizando LLMs via Groq.
- Integração com WhatsApp para abertura de conversas com mensagens revisadas.
- Histórico de interações e acompanhamento comercial.

**Destaque técnico:** integração entre frontend, API Python, persistência de dados e serviços externos de inteligência artificial.

[🔗 Visualizar repositório](https://github.com/nandoalvesferreira20-png/loung-prospect)
